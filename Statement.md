Statement File – BMI Calculator Project
1. Problem Statement

Many people want to know an easy and quick way of determining whether their body weight is within the normal range for a given height and weight. One of the most prevalent measures in this respect is called Body Mass Index. Yet, people often lack an easy-to-use tool to calculate BMI correctly without resorting to external applications or manual formulas.

This project addresses this need by implementing a Python program that takes user input - height in inches and weight in pounds - calculates BMI, and categorizes the user into standard health groups like underweight, healthy, overweight, or obese.

2. Project Scope

The scope of this project will include:

Read user input for height in inches and weight in pounds.

Calculate Body Mass Index using the standard imperial formula.

Classifying the BMI result into medically recognized categories.

Displays the calculated BMI and related health category.

This guarantees that the program runs on any system with Python installed.

The project does not include:

Graphical user interface (GUI)

Data storage or history tracking

Medical advice or individual health consultations

Error handling for invalid input

3. Target Users

The list of primary users for this BMI Calculator includes:

People who need only a simple tool to check their BMI.

Students learning basic Python programming and health-related calculations.

Fitness beginners who want to check their health status quickly.

Educators or trainers who utilize BMI as part of teaching demonstrations or exercises.

4. High-Level Features

Key features of the BMI Calculator include the following:

User Input Handling

Accepts height in inches.

Accepts weight in pounds.

Calculation of BMI

Calculates BMI using the following formula:

BMI = weight / height² × 703

BMI Classification

Categorizes the user into one of the following:

Severely underweight

Underweight

Healthy

Overweight
