BMI Calculator in Python
Overview of Project

Below is a simple Python-based project for a BMI Calculator that takes the user's height (in inches) and weight in pounds as input. It calculates the BMI using the standard formula for imperial units and further classifies the user's health category based on the obtained BMI result, such as underweight, healthy, overweight, and so on.

This program runs in the terminal, with clear output showing both the value of BMI and the health classification.

Features

Accepts height in inches and weight in pounds

Calculates BMI using the imperial formula.

Categorizes BMI:

Severely underweight

Underweight

Healthy

Overweight

Obese

Simple and user-friendly interface

Clean output with BMI and category

Technologies / Tools Used

Python 3.11

Standard Python input/output (no external libraries needed)

_INTRUCTIONS TO INSTALL & RUN PROJECT _

1. Install Python

Ensure that your machine has Python 3.11 installed.


Check with:

python --version

or

python3 --version

2. Create a Python file

Create a new file, for instance:

bmi_calculator.py


3.Run the Program

Use your terminal/command prompt:

python bmi_calculator.py

or

python3 bmi_calculator.py

How to Test ?
To test the program:

Run the script

When prompted, type:

Height in inches
Weight in pounds

The program will print:


Your calculated BMI Your health classification Input Test Example ➤ Enter your height in inches: 70 Enter weight in lbs: 150 ➤ Example Output Your BMI is: 21.52 and you are: healthy Try various height/weight combinations to test the different BMI categories
